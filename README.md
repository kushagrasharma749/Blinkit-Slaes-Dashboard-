Blinkit Sales Analysis Dashboard | Power BI

📌 Purpose:
The purpose of this project was to analyze Blinkit’s sales performance and provide data-driven insights into customer behavior, product demand, and regional sales distribution. The dashboard helps businesses make better decisions regarding product strategy, pricing, and inventory management.

📊 Data Source:

Dataset taken from Kaggle (Blinkit Sales Data)

Data included product details, sales transactions, customer demand, and profit information

🛠️ Technology & Tools Used:

Power BI → Dashboard creation and visualization

Power Query → Data cleaning and transformation

DAX (Data Analysis Expressions) → Custom calculations (Profit %, YoY growth, Average sales, etc.)

Excel/CSV → Source file handling and pre-processing

✨ Features & Highlights:

Built an interactive Power BI dashboard to track KPIs like Total Sales, Profit, Average Order Value, and Quantity Sold.

Used slicers and filters for drill-down analysis (by region, category, product type, and time).

Created visualizations such as bar charts, line charts, maps, and KPI cards for better storytelling.

Identified top-selling products, high-profit categories, and regional sales trends.

Implemented trend analysis to highlight sales patterns and seasonal demand.

Delivered business insights on customer preferences and profitability to support decision-making.

💡 Key Highlights:

Improved data usability through structured data modeling.

Automated data refresh for real-time dashboard updates.

Designed a user-friendly interface for stakeholders to explore insights easily.
